# 📊 FunPay Profit Calculator & Analytics

Привет! Это мой первый проект на Python. Он довольно простой, но очень полезный для тех, кто занимается продажами на FunPay и хочет точно знать свою чистую прибыль без сложных ручных расчетов.

Суть программы — автоматический расчет реального заработка с учетом комиссий площадки и поставщиков, а также ведение удобной локальной таблицы товаров за текущую сессию.

---

## 🚀 Основные возможности

Программа разделена на два удобных интерактивных модуля:

### 1. 🧮 Умный калькулятор
* **Учет комиссии площадки:** Программа автоматически закладывает базовую комиссию FunPay (14%) на вывод/продажу.
* **Гибкая закупка:** Возможность указать чистую цену товара у поставщика.
* **Учет скрытых расходов:** Если при покупке или пополнении баланса есть дополнительная комиссия (например, 6% на пополнение), калькулятор сам рассчитает её (просто введите `0.06`).
* **Моментальный итог:** Вы сразу видите чистую выгоду с одной штуки.

### 2. 📋 Таблица истории
* Больше не нужно записывать результаты на листок! Все вычисления из калькулятора автоматически заносятся в структурированную базу данных.
* Перейдя в этот раздел, вы увидите аккуратный список всех просчитанных за сессию товаров с их финальной чистой прибылью.

---

## 🎨 Особенности интерфейса
* Программа написана полностью на чистом Python, но имеет яркий дизайн консоли благодаря **ANSI-цветам**.
* Использован стильный **ASCII-арт** для главного меню, что делает работу с утилитой приятной визуально.
* Реализована плавная очистка экрана с помощью модуля `os` — никакого системного мусора в консоли при переходах между разделами!

---

## 🛠 Запуск проекта

1. Убедитесь, что у вас установлен Python 3.x.
2. Скачайте файл `main.py`.
3. Запустите его через терминал или командную строку:
   ```bash
   python main.py
   ```

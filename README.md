# 📊 FunPay Profit Calculator & Analytics

Привет! Это мой первый проект на Python. Он довольно простой, но очень полезный для тех, кто занимается продажами на FunPay и хочет точно знать, за какую цену выставлять товар, чтобы получить желаемую чистую прибыль без сложных ручных расчетов.

Суть программы — обратный расчет цены выставления с учетом всех комиссий (площадки и закупки), а также ведение удобной локальной таблицы товаров за текущую сессию.

## 🚀 Основные возможности

Программа разделена на два удобных интерактивных модуля:

### 1. 🧮 Умный калькулятор цены выставления
* **Расчет от желаемой прибыли:** Вы указываете, сколько хотите заработать «чистыми», а программа сама считает итоговую цену, за которую нужно выставить лот.
* **Учет комиссии площадки (12%):** Калькулятор автоматически закладывает комиссию биржи в финальную стоимость товара, чтобы вы не ушли в минус.
* **Учет комиссии при закупке:** Если при покупке товара у поставщика или пополнении баланса есть дополнительная комиссия, программа учтет её и посчитает реальную себестоимость.
* **Удобный ввод процентов:** Больше не нужно переводить проценты в дроби в уме — просто введите обычное число (например, `2` вместо `0.02`).
* **Детальный чек:** Сразу после расчета вы видите реальные затраты на закупку, цену для выставления, сумму комиссии биржи в рублях и вашу чистую прибыль.

### 2. 📋 Таблица истории
* Больше не нужно записывать результаты на листок! Все вычисления из калькулятора автоматически заносятся в структурированную таблицу за сессию.
* Перейдя в этот раздел, вы увидите аккуратный список всех просчитанных товаров с их финальными показателями.

## 🎨 Особенности интерфейса и надежность
* **Защита от опечаток и вылетов:** Встроенная валидация ввода (`try/except`) не даст программе закрыться с ошибкой, если случайно ввести буквы вместо цифр, а проверка ответов «Да/Нет» понимает обе раскладки клавиатуры.
* **Яркий дизайн:** Программа написана на чистом Python с использованием ANSI-цветов и стильного ASCII-арта для главного меню.
* **Чистая консоль:** Реализована плавная очистка экрана с помощью модуля `os` — никакого системного мусора при переходах между разделами.

## 🛠 Запуск проекта

1. Убедитесь, что у вас установлен **Python 3.x**.
2. Скачайте файл `main.py` (или клонируйте репозиторий).
3. Запустите программу через терминал или командную строку:
```bash
python main.py
```
